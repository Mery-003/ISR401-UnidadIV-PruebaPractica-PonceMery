\begin{infobox}
\textbf{Caso práctico.} Una tienda en línea requiere un módulo para gestionar los pedidos de sus clientes. Un Cliente, identificado por cédula/RUC, nombre y correo, puede realizar cero o más Pedidos. Cada Pedido posee identificador, fecha y total, contiene una o más Líneas de pedido y cada línea referencia un Producto con código, descripción, precio y stock. Al registrar un pedido, el sistema verifica la disponibilidad de stock: si existe, confirma el pedido; si no, notifica el faltante. Un pedido confirmado puede despacharse, entregarse o anularse mientras no haya sido entregado. El sistema debe registrar pedidos con rapidez y proteger los datos personales del cliente.
\end{infobox}

\begin{taskbox}{Enunciados de los requisitos}
\textbf{RF-01 - Registrar pedido.} El sistema deberá registrar el pedido con los datos correspondientes.

\textbf{RF-02 - Verificar disponibilidad.} Cuando se solicite confirmar un pedido, el sistema deberá verificar el stock de todas las líneas; si existe disponibilidad deberá confirmar el pedido y, si existe un faltante, deberá notificarlo.

\textbf{RNF-01 - Eficiencia de desempeño.} \textbf{Característica ISO/IEC 25010:2023:} Eficiencia de desempeño. El 95\% de los registros de pedidos deberá completarse en menos de 3 segundos.

\textbf{RNF-02 - Seguridad.} \textbf{Característica ISO/IEC 25010:2023:} Seguridad. El sistema deberá proteger los datos personales del cliente, rechazando el 100\% de los intentos de acceso no autorizado.
\end{taskbox}
